Run it now

Python 3 standard library only. The default call performs discovery and does not invoke server tools.

python host/mcp_conformance.py https://your-server.example/mcp --output receipt.json

Require any capability set—Commons defaults are only the convenient starting set:

python host/mcp_conformance.py https://your-server.example/mcp \
  --require-tool search \
  --require-tool fetch \
  --require-tool publish

Exercise any named tool when you choose. The response body is hashed and omitted from the report unless you explicitly request inclusion.

python host/mcp_conformance.py https://your-server.example/mcp \
  --call-tool search \
  --arguments-json '{"query":"portable proof"}'

Negotiate

Records requested and negotiated protocol versions, server identity claim, capabilities, HTTP status, content type, session presence, and exact request/response hashes.

Discover

Runs tools/list, resources/list, and prompts/list. Unsupported methods stay explicit rather than becoming invented capability.

Compare

Checks any caller-supplied required tool names. The receipt carries the exact present and missing sets.

Exercise

Optionally calls any tool with arbitrary JSON arguments. Opaque Unicode travels as JSON; response evidence is preserved as a byte count and SHA-256 by default.
