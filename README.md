# Commons

Commons contains tools for service integrations, workflow automation, applied research, and commercial product demonstrations.

- `host/`, `tools/`, and `infra/` provide execution and integration utilities.
- `integrations/`, `api/`, and `services/` contain service adapters and application interfaces.
- `revenue/`, `commercial/`, and `products/` contain reusable business tools and demonstrations.
- `research/` and `competitions/` contain reproducible research and evaluation code.
- `lda/` and `android/` contain Android application source.

Components use their own configuration and dependency files. Refer to the documentation alongside each component before running it.
