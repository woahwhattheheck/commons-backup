# Saved C5 cut and deletion navigation

This index consumes the exact accepted #31636 occupancy/Pascal result for five parts of six. It adds all 2^29 canonical cuts with vertex 0 on the selected side, grouped by deletion cost.

The maximum cut has 144 edges. All 315 distinct minimum deletion sets remove 36 edges; their canonical vertex sides and 33 complete reader outputs are retained. The bound is the classical C5 blow-up sharpness value, not a new extremal theorem.
