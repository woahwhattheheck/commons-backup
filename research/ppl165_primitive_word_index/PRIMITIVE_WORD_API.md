# Primitive binary-word prefix index

This package counts and navigates primitive binary words of one fixed positive length. It retains a short divisor/Möbius ledger and powers of two instead of listing the represented family. Prefix counts drive exact lexicographic ranks, selections and pages. The complete actual consumer is length 70; other accepted lengths and error branches were source-inspected only.

## Sources and scope

A primitive word is a nonempty word that is not a whole-word power \(u^k\) for an integer \(k\ge2\). Repeated letters and repeated internal factors are permitted. The empty word is excluded. [Shallit's official slides](https://cs.uwaterloo.ca/~shallit/Talks/bc4.pdf), printed slide 29, ask whether the language of primitive binary words is context-free.

The classical formula
\[
P_n(q)=\sum_{e\mid n}\mu(e)q^{n/e}
\]
is explicitly recorded by Golomb, Gordon and Welch in [*Comma-free codes*, printed pages 202–203](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/B78C35132E2BCD4A14459BE6A142FF30/S0008414X00045296a.pdf/commafree_codes.pdf). It counts linear words. A primitive rotation class has \(n\) distinct words, so \(P_n(q)/n\) counts a different family. The paper's comma-free-dictionary maximum is also a different quantity. No original-discovery priority is asserted here.

Amarilli, Monet, Raphaël and Salvati, [*On the Complexity of Language Membership for Probabilistic Words*, STACS 2026, §6](https://drops.dagstuhl.de/storage/00lipics/lipics-vol364-stacs2026/html/LIPIcs.STACS.2026.5/LIPIcs.STACS.2026.5.html), DOI 10.4230/LIPIcs.STACS.2026.5, still describe nonunary primitive-language context-freeness as unknown. Proposition 6.4 already provides polynomial-time probabilistic counting, with arithmetic-cost qualification. Their introduction also relates prefix counting to navigation. This API claims neither a new general counting-complexity result nor a resolution of the language question.

## Exact prefix formula

Fix \(n\ge1\). All positions are labelled \(0,\ldots,n-1\), and \(0<1\) is the lexicographic order. For each divisor \(d\mid n\), a word with period dividing \(d\) repeats its first \(d\) symbols exactly \(n/d\) times.

Let \(v\) be a prefix of length \(\ell\le n\). Its compatibility with \(d\) is exactly
\[
v_j=v_{j-d}\qquad(d\le j<\ell).
\]
If any comparison fails, there is no \(d\)-periodic completion. Otherwise the first \(\min(d,\ell)\) residue positions are fixed and the other positions among the first \(d\) are free. Hence
\[
C_d(v)=
\begin{cases}
2^{d-\min(d,\ell)},&v\text{ is compatible with }d,\\
0,&\text{otherwise}.
\end{cases}
\]

The primitive completion count is
\[
P_n(v)=\sum_{d\mid n}\mu(n/d)C_d(v).
\]

To see this directly, fix one completed word with primitive root length \(r\mid n\). Its divisor periods are precisely the multiples \(d\) of \(r\) dividing \(n\). For example, this follows from the cyclic period subgroup: shifts fixing the word form a subgroup of the cyclic group of order \(n\), generated by its least positive divisor period. The completed word's total weight in the displayed sum is
\[
\sum_{\substack{d\mid n\\r\mid d}}\mu(n/d)
=\sum_{e\mid n/r}\mu(e)
=\begin{cases}1,&r=n,\\0,&r<n.\end{cases}
\]
The last identity follows by expanding \(\prod_{p\mid n/r}(1-1)\), with empty product 1. Summing these weights over completions proves the formula. This is a finite specialization of classical Möbius inversion, not a new primitive-word theorem.

For the empty prefix every \(C_d\) is \(2^d\), giving the usual count. For a full-length word every compatible \(C_d\) is 1, and the result is its primitive-membership indicator. At length 1 both symbols are primitive. Length 0 is outside the API; the empty prefix is valid when \(n>0\).

## Incremental navigation

A state retains its prefix, one compatibility flag per divisor and the primitive completion count. Appending a bit at position \(\ell\) only requires a new equality against position \(\ell-d\) when \(\ell\ge d\). A flag that is already false stays false. The new count uses the saved power \(2^{\max(d-\ell-1,0)}\) for each compatible divisor.

The sets of primitive completions beginning with \(v0\) and \(v1\) are disjoint and exhaust those beginning with \(v\). Every word in the first set precedes every word in the second.

- Ranking adds \(P_n(v0)\) whenever the input takes the 1 branch. The returned insertion rank is the number of primitive words strictly smaller than the input, even if that input is nonprimitive. A nonprimitive input has no family rank.
- Selection compares the residual rank with \(P_n(v0)\). It takes 0 when the residual is smaller; otherwise it subtracts that count and takes 1. After \(n\) positions it must reach one primitive word with residual zero.
- A page performs selection for each requested rank. It does not construct the family or a persistent prefix tree.
- Membership checks every retained divisor period, reports its first conflict when present, and chooses the least compatible divisor as the primitive-root length. Repetition count is \(n/r\).

Each state advancement visits the retained divisor rows. Each membership call makes bounded character comparisons against those periods. BigInt arithmetic, string construction and page calls have real costs; this implementation does not assert unit-cost arithmetic or a new optimal complexity bound. The actual operation counters below make the executed work explicit.

## Public contract

The module is plain CommonJS with no imports or I/O. It exports:

- `PRIMITIVE_WORD_LIMITS`
- `compilePrimitiveWords({length, provenance?})`
- `openRetainedPrimitiveWords(snapshotOrJSONString)`

Construction returns `{status, snapshot, work, snapshot_chars}`. The constructor trial-factors the small quotients \(n/d\), records complete prime/exponent factors and Möbius signs, builds powers of two by doubling, and records every signed total-count term. Its snapshot schema is `commons.binary_primitive_word_index/v1`.

The reader returns these operations:

| Method | Contract |
| --- | --- |
| `summary()` | Length, alphabet, primitive/composite/all counts, row sizes and validation scope |
| `source()` | Outward copy of the identified input provenance |
| `prefix(v)` | Completion counts and every divisor's compatibility, free positions, signed term and first conflict |
| `membership(w)` | Full-length word, primitive flag, primitive root, repetition count and all period witnesses |
| `rank(w,{trace?})` | Zero-based rank or null, insertion rank, optional complete \(n\)-step trace |
| `select(rank,{trace?})` | Word at the requested rank, optional complete \(n\)-step trace |
| `page({start?,limit?})` | Consecutive ranks, total and continuation position |
| `snapshot()` | Outward copy of the complete saved snapshot |
| `statistics()` | Outward copy of current operation counters; does not increment the query count |

Every word and prefix is a JavaScript string using only ASCII `0` and `1`. Rank and membership inputs must have exactly the indexed length. Prefixes may be empty. Rotations remain distinct, and leading zeros are significant.

Ranks accept nonnegative BigInt, safe integer Number, or canonical decimal strings with no leading zeros other than `"0"`. Returns use decimal strings for large integers. Unsafe Numbers are refused rather than rounded. Selection requires \(0\le r<P_n\); page start may equal the total and then produces an empty page. Page limit 0 is permitted and advances no position. No negative ranks or wraparound are supported. Trace collection is enabled only by `trace:true`.

### Bounds

| Quantity | Hard limit |
| --- | --- |
| Fixed word length | Integer 1 through 1024 |
| Saved snapshot serialization | 1,000,000 JavaScript characters |
| Provenance serialization | 16,384 characters |
| Rank/saved-natural decimal input | 310 digits |
| Page output | 0 through 32 words, default 16 |

All stored counts are BigInt-compatible strings. The maximum count is at most \(2^{1024}\), within the decimal bound. Indices, small factors and loop counters are bounded safe Numbers. A full prefix trace has at most 1024 rows. A page repeats selection and thus may perform more state work than a single selection. Limits refuse the operation; there is no automatic cap expansion or partial-family completeness claim.

### Saved-data trust boundary

Opening a snapshot parses an outward copy, checks the schema and conventions, bounds, power-table length, canonical decimal fields, sorted divisor rows, divisor/quotient relations, allowed Möbius sign values, factor-field bounds and divisor endpoints. It also checks `primitive_total + composite_total = powers_of_two[n]`.

It **does not** reconstruct factorization, establish factor primality, recompute Möbius signs, check completeness of the divisor list, replay power doubling or authenticate the signed total ledger. These saved arithmetic and coverage facts remain premises from the identified constructor. A structurally acceptable malicious snapshot can still give incorrect answers. Negative state counts or impossible final selection counts are refused, but those checks do not make the loader a mathematical verifier.

The returned summary labels this scope. Source, snapshot and statistics outputs are copied; query results do not expose the internal saved tables. The loader's positive claims are structural and total-partition checks, not independent proof of provenance.

## Use in a saved-data consumer

The following illustrates the API; it is not an additional recorded execution:

```javascript
const api = require("./primitive_word_index.cjs");
const record = require("./length70_words.json");
const index = api.openRetainedPrimitiveWords(record.constructor.snapshot);

const result = index.prefix("000001");
const page = index.page({start: "36893488146345360866", limit: 5});
```

A connected V8 caller can evaluate the same CommonJS source using `new Function("module","exports",source)` and pass the parsed snapshot directly. The module itself performs no file or network operation. Publication and source custody are separate from the mathematical API.

The deliverable is an exact finite navigation capability with explicit saved-data provenance. It does not decide whether the full primitive-word language is context-free, and its lexicographic ordering is an interface convention rather than a new theorem about rotation classes.
