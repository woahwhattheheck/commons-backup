# B₂[2] subsets of [1,19]

The complete finite index contains 78,736 admissible subsets, with maximum size 9 attained by 224 members. Representations are unordered a+b with a≤b; diagonal pairs count once. All 224 maximizers and 37 actual saved-reader responses are retained.

Load all four node shards in manifest order before opening the index. The reader supports cardinality, conditions, rank/select, pair fibers, exact rejection witnesses and one-element extensions. An inclusion-maximal size-eight example is distinct from a maximum-size member.

This is a finite-host classification and navigation capability, not a resolution of Erdős 158's infinite-density question or a new record claim. No previous B3, Sidon, sum-product or accepted pair-table calculation was replayed.
