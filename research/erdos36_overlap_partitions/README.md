# Minimum-overlap partition atlas

Exact signed cross-correlation and conditional navigation for balanced labelled partitions of a finite interval.

The complete n=9 index contains all **48,620** splits of {1,...,18}. Their minimum maximum overlap is **4**, attained by **156** labelled splits. Twelve full profile shards and 12,283 complement/reflection orbits support saved queries. All 156 minimizers and nine complete conditional families are retained.

Read [OVERLAP_PARTITIONS_API.md](OVERLAP_PARTITIONS_API.md) for the definitions, finite proof, ordering, API, source attribution, complete file identities and work accounting. Use [overlap_partitions.cjs](overlap_partitions.cjs), [balanced9_index.json](balanced9_index.json) and [saved_reader_queries.json](saved_reader_queries.json).

A and B have ordered roles and differences are signed. Symmetry orbits do not quotient labelled counts. This finite result is not a new asymptotic bound, record, prize submission or solution of the general minimum-overlap question.
