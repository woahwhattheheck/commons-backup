# Complete explicit exclusion of the remaining Erdős 1142 tail

Every one of the **10,618** saved candidates from
[the nonprimitive refinement](NONPRIMITIVE_REFINEMENT.md) now has an explicit
proper-divisor witness. **Zero candidates remain in `4109 < n <= 2^44`.**

The complete factorization data is in
[residual_exclusion_witnesses.json](residual_exclusion_witnesses.json). It is
bound to the previously published candidate list by its exact Git blob.
Neither earlier sieve was rerun. The existing public classifier was used
without a source change.

## What is proved by the data and preceding reductions

Write `E(n)` for the Erdős 1142 property: `n > 2` and
`n - 2^k` is prime whenever `k >= 1` and `2^k < n`.

The dependency chain is:

1. The published contribution `8b087102…` supplies the covering-congruence
   theorem and p = 3, 5, 11, 13, 19 instances.
2. [Commons #16080](https://github.com/woahwhattheheck/commons/pull/16080) supplies
   the p = 29, 37 continuation and four arithmetic intervals covering every
   possible `E(n)` in `(4109, 2^44]`.
3. [Commons #31083](https://github.com/woahwhattheheck/commons/pull/31083)
   excludes 454,717 of those 465,335 arithmetic candidates and saves the
   remaining 10,618 integers in
   [residual_candidates.json](residual_candidates.json).
4. The factorization data here excludes each saved integer.

For each input candidate `n`, the new data supplies integers `k,p,q` such
that

```text
1 <= k <= 43,
p > 1,
q > 1,
n - 2^k = p*q.
```

The positive product ensures `2^k < n`; the two nontrivial factors make the
difference composite. Thus no saved candidate has `E(n)`. Combined with the
accepted coverage of the preceding reductions, this gives

```text
For every integer n with 4109 < n <= 17592186044416, not E(n).
```

The conclusion concerns that finite tail. This continuation does not analyze
`n <= 4109` or `n > 2^44`, and does not settle the global conjecture.

The finite bound is classical: the
[Erdős problem page](https://www.erdosproblems.com/1142) attributes the
classification through `2^44` to Mientka and Weitzenkamp (1969), and
[OEIS A039669](https://oeis.org/A039669) lists their paper and later search
information. This continuation supplies reusable explicit factorization data
for the existing carrier's remaining tail; it claims no new search record or
novel resolution. The original Ghory/Nash mechanism and sponsor contribution
retain the attribution recorded in the preceding guide.

## Compact witness format

The data uses tuples

```text
[candidate_index, exponent, divisor, cofactor].
```

For a row `[i,k,p,q]`, the candidate is `candidates[i]` in the exact source
JSON identified in `source_candidates.git_blob_sha`; indices are zero-based.
The rows contain every index from 0 through 10,617 exactly once, in order.
The fixed input reference avoids copying its 10,618 large integers into another
dataset, while retaining a complete factorization for each.

The first three rows are:

```text
[0, 12, 53, 1663]
[1, 16, 61, 719]
[2, 9, 179, 2957]
```

They encode

```text
92235  - 4096  = 53  * 1663,
109395 - 65536 = 61  * 719,
529815 - 512   = 179 * 2957.
```

The third equation is the single witness attributed to 179. The machine-readable
`survivors` array is empty. These saved equations can be consumed directly;
there is no need to regenerate the candidate list or rerun the completed
divisor search.

All values are exact integers within JavaScript's safe-integer range.
The largest input is below `2^44`, and the classifier reports integer
differences and cofactors. The proof obligation for later formalization is the
finite input coverage together with these elementary equations and factor
bounds, rather than trusting a numerical primality oracle.
