# PPL006 finite 1–3–5 box fibers

Complete conditional navigation for the labelled box 0<=x,y,z,w<=31 with x+3y+5z=t², t>=0.

The compact certificate has 1,511 triple skeletons representing 48,352 ordered quadruples, 13,478 joint (n,t) fibers and 2,885 distinct targets. It includes zero and retains named coordinates. There is no permutation quotient.

Read [BOX_FIBERS_API.md](BOX_FIBERS_API.md) for the exhaustion argument, schema, inclusive filters, tuple-lex rank/select, complete 163-response reader and exact query-work counts. [SOURCE_QUALIFICATION.md](SOURCE_QUALIFICATION.md) binds Sun's dated author abstract and the finite scope. The full constructor and reader outputs are preserved in certificate.json and saved_reader.json; public_checkpoints.json identifies their native blob acknowledgements.

This is a fixed-box representation API, not verification of an n interval, a conjecture proof or a prize submission. Empty fixed-box fibers make no assertion about representations outside the box. Protected A308734/PPL021 calculations and source verification ranges were not replayed.
