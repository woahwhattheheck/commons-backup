# OSS funding-route freshness recensus

Operation: `OSS-FUNDING-ROUTE-FRESHNESS-RECENSUS-20260916-ZSOL17`  
Carrier: Commons issue #15170  
Upstream retained generation: `research/oss_sponsor_route_map/route_map.json`

This directory contains an **offline** recensus compiler. It does not fetch a provider, claim a bounty, contact a maintainer, submit an application, mutate a provider, or assert award/payment/revenue. Retrieval is intentionally outside this product: a separately controlled evidence adapter must produce a trusted observation set.

## Contract

Inputs:

1. the retained prior sponsor/funding map; and
2. a trusted `oss-funding-route-observation-set/v1` generated by an evidence adapter.

Every observation must bind the exact prior operation/generation/map SHA-256, exact opportunity ID, exact source ID and exact prior source URL. The compiler rejects source substitution, missing/extra routes, duplicate/ambiguous aliases, future observations, observations generated before the prior snapshot, malformed/duplicate/non-finite JSON, unsupported fields and untrusted adapter authority.

Each route emits exactly one result:

- `SAME_OPEN` — current open state and tracked source/economic fields are unchanged;
- `CHANGED_REVIEW` — the route is still open-like, but current state, currentness fact or economic fields changed;
- `CLOSED` — the trusted observation marks the route closed;
- `STALE` — the observation is older than the fixed 72-hour freshness window at observation-set generation;
- `CONFLICT` — the trusted observation set carries a contradiction that requires owner review.

Economic changes can never remain `SAME_OPEN`. Any `cash_kind` or `advertised_value` change adds `ECONOMIC_REVIEW_REQUIRED`.

The report includes prior source-record digest, new trusted source digest, prior/new observation timestamps, exact changed fields and deterministic downstream block reasons. The verifier recomputes the complete canonical report and requires exact bytes.

## Observation-set shape

```json
{
  "schema": "oss-funding-route-observation-set/v1",
  "operation": "OSS-FUNDING-ROUTE-FRESHNESS-RECENSUS-20260916-ZSOL17",
  "generated_at_utc": "2026-09-17T01:30:00Z",
  "adapter": {
    "id": "controlled-adapter-id",
    "generation": "adapter-generation-id",
    "authority": "TRUSTED_EVIDENCE_ADAPTER"
  },
  "prior_generation": {
    "operation": "OSS-SPONSOR-ROUTE-EVIDENCE-MAP-20260916",
    "generated_at_utc": "<exact prior generated_at_utc>",
    "map_sha256": "<sha256 of exact prior file bytes>"
  },
  "observations": [
    {
      "opportunity_id": "<exact prior opportunity id>",
      "source_id": "<exact prior source id>",
      "source_url": "<exact prior source url>",
      "source_sha256": "<sha256 of adapter-retained authoritative source bytes>",
      "observed_at_utc": "2026-09-17T01:29:00Z",
      "current": "OPEN",
      "currentness_fact": "<trusted current fact>",
      "econ": {
        "cash_kind": "CASH",
        "advertised_value": "<value or null>"
      },
      "aliases": [],
      "conflicts": []
    }
  ]
}
```

`source_sha256` is the digest of the new retained authoritative source bytes from the evidence adapter. The report's `previous_source_record_sha256` is explicitly a digest of the prior map's normalized source record, because the upstream retained map predates raw-source SHA binding and does not contain a prior raw-byte digest.

## Commands

Compile a trusted recensus:

```bash
python research/oss_funding_route_recensus/recensus.py compile \
  --prior research/oss_sponsor_route_map/route_map.json \
  --observations /path/to/trusted-observations.json \
  --output /new/path/recensus-report.json
```

Verify exact report bytes:

```bash
python research/oss_funding_route_recensus/recensus.py verify \
  --prior research/oss_sponsor_route_map/route_map.json \
  --observations /path/to/trusted-observations.json \
  --report /path/to/recensus-report.json
```

Run the no-network synthetic reference demo:

```bash
python research/oss_funding_route_recensus/demo.py
```

The reference demo deliberately replays the prior retained facts through a synthetic adapter so the expected result is `SAME_OPEN` for every route. It is a mechanics demo only and **not currentness evidence**.

Validation:

```bash
python -m unittest -v research.oss_funding_route_recensus.test_recensus
python -O -m unittest -v research.oss_funding_route_recensus.test_recensus
python -m py_compile \
  research/oss_funding_route_recensus/recensus.py \
  research/oss_funding_route_recensus/demo.py \
  research/oss_funding_route_recensus/test_recensus.py
```

## Authority ceiling

All report authority flags are false. A recensus result may block stale or changed work; it does not authorize implementation, external contact, application/submission, bounty claim, provider mutation, payment handling, accounting, award or revenue recognition.
