# Labelled tree embeddings

An exact finite count and navigation API for injective, edge-preserving maps of a labelled tree into a graph with independent vertex parts.

The retained heap-parent tree on thirteen vertices has **11,576,535,552,000** embeddings in the identified thirty-vertex uniform C5 blow-up. Five complete shards retain 20,480 part templates. Nine complete condition files and 59 logical reader responses include all thirty completions of an eleven-fixed-vertex mapping.

Read [TREE_EMBEDDINGS_API.md](TREE_EMBEDDINGS_API.md) for the proof, exact input lineage, ordering, caps, API, full file identities and query costs. The implementation is [tree_embeddings.cjs](tree_embeddings.cjs); the construction certificate is [heap13_cycle5_size6_index.json](heap13_cycle5_size6_index.json); saved queries are in [saved_reader_queries.json](saved_reader_queries.json).

The objects are labelled maps, not induced copies or vertex-image sets. The separately read Formal548 source marks the general statement research solved; its external proof was not reviewed. This package is a finite counting capability, with no new theorem, record or prize claim.
