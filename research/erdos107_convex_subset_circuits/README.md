# Convex subsets and empty polygons in a 15-point host

The complete index retains 455 nonzero orientation determinants, 538 containment circuits and all 32,768 subset classifications. There are 2,589 convex subsets and 687 empty convex polygons. The largest convex subset has nine vertices; the largest empty polygons have seven, with seven maximizers.

[The API guide](CONVEX_SUBSET_CIRCUITS_API.md) explains exact coordinates, source attribution, positive-affine invariance, numeric-mask ordering, full-host emptiness and the general-position certificate. Use `convex_subset_circuits.cjs` with `fifteen_point_circuits.json`; all 41 actual reader outputs are in `saved_reader_queries.json`.

These are finite-host results. They do not establish the unrestricted Erdős–Szekeres formula or turn an ordinary convex polygon into an empty one. The prior E97 distance arrangement and Danzer proof were not replayed.
