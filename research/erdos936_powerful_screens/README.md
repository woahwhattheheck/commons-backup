# Powerful-number local screens

Exact periodic selected-prime exclusions for 2^n±1, using the identified odd primes through 17. The complete saved cycles and CRT-coordinate suffix counts classify a valid period of 4,084,080 exponent phases without enumerating the global phase space. A local witness proves nonpowerfulness; passing the finite screen remains unclassified.

See [the API and proof guide](POWERFUL_SCREENS_API.md), [the module](powerful_screens.cjs), [the full construction](primes17_power_screen.json) and [all 43 saved reader responses](saved_reader_queries.json).

Rank/select uses coordinate-lexicographic order within positive period blocks, not increasing exponent order. The package adds finite modular navigation and huge-exponent witnesses; it does not resolve Erdős 936's exponential or factorial finiteness questions. Source definitions, imported prime provenance and all execution limits are explicit in the guide.
