# Finite pair sums-and-products colorings

Exact classification of all labelled binary colorings of [1,22] avoiding each in-range {x,y,x+y,xy} pattern for positive x<y.

The 34 constraints have 1,744 avoiding colorings. A complete 1,002-node DAG and 10,312 base coefficient cells support exact weight counts, fixed-bit conditions and lexicographic rank/select. All 37 fresh reader outputs are retained, including six rank/select matches and 3,436 newly computed conditional coefficients.

See [the API guide](PAIR_COLORINGS_API.md) for source attribution, the distinction from Moreira's three-value theorem, exact coverage, query ordering and limits. This finite pair-family result does not resolve Erdős 172's arbitrary-size nonempty-subset sums/products question.
