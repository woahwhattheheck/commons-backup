# Erdős 885: common factor differences on a fixed host

The thirteen positive integers inherited from the identified binomial exception factors have pairwise disjoint factor-difference sets: 4,994 unordered factor pairs give 4,994 distinct differences. Every one of the 8,178 host subsets of size at least two has empty intersection. This complete finite negative result does not concern the known constructions on other integers or the general Erdős question.

[The API guide](COMMON_FACTOR_DIFFERENCE_API.md) documents the sources, exact input lineage, divisor/support reduction, empty-intersection convention and query work. [The module](common_factor_difference_index.cjs) reads the complete snapshot assembled from [the manifest](host13_manifest.json), two host-pair shards and [difference records](differences.json).

[The 56 reader responses](saved_reader_queries.json) include 21 matching inverse ranks, all qualifying singletons, positive and negative witnesses, and saved factor/shared-difference pages. [Complete query caches](saved_condition_caches.json) are retained.

The one already computed host integer was reused. No prior binomial valuation, prime test, factorization, known example or proof was replayed. The fixed host and inherited factor premises delimit the result.
