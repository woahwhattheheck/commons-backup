# Five-piece right-triangle hierarchy

Exact rational navigation for a declared five-piece subdivision of the 1–2–sqrt(5) triangle.

Depth 26 represents **1,490,116,119,384,765,625** labelled leaf triangles in **206** orientation classes. Complete tables through that depth contain only **2,754** orientation cells.

- [Coordinates, proof, sources and API](FIVE_PIECE_TRIANGLES_API.md)
- [CommonJS module](five_piece_triangles.cjs)
- [Complete depth-26 certificate](depth26_triangle_certificate.json)
- [All 30 saved-reader outputs](saved_reader_queries.json)

The API provides global and orientation-restricted address navigation, exact leaf vertices and boundary-inclusive point location. All arithmetic is integral/rational; it does not enumerate the represented leaf family.

Conway–Radin attribution and Radin–Sadun's readable five-piece description are credited. The diagram screenshot returned only a placeholder, so literal diagram matching is not claimed; the exact coordinate template and partition are declared and proved directly. This finite index does not classify all congruent-triangle dissection counts or claim a new admissible number.
