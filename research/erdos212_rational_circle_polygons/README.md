# Rational circle polygons

A complete exact index for 64 rational-distance points on the unit circle. It retains 2,016 chords in 757 distance classes and the maximum-perimeter anchored eight-vertex polygon family.

Among 553,270,671 candidate vertex subsets containing anchor 0, the maximum is 2308/377, attained by four polygons. All four and 31 complete reader outputs are saved.
