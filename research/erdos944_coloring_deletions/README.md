# Coloring and edge-deletion navigation

Exact finite response index for the accepted 11-vertex Mycielski graph. The package retains 29,525 canonical partitions into at most three classes, 23,114 required-deletion masks, and complete count/rank/select data for declared edge-deletion conditions. At budget ten it represents 96,931,792 coloring/deletion incidences; these are not counts of distinct deletion sets.

See [the API and proof guide](COLORING_DELETIONS_API.md), [the source](coloring_deletions.cjs), [the construction manifest](mycielski_coloring_deletions.json), and [the 33-response reader record](saved_reader_queries.json). All row, class and condition files are complete and pinned in the manifests.

The graph construction and imported chromatic premises are prior results. This finite index does not resolve Erdős 944’s all-r existence question or supply a robust graph. Every singleton deletion in this input permits a three-coloring. Source definitions, current formal annotations, the unpublished-proof boundary and once-only execution lineage are detailed in the guide.
