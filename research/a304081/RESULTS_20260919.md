## Interpretation

- No counterexample was found.
- The exact local scan sharpened the observed low-count target from 10
  representations to 7 at `n=296591227539`.
- That low-count point is a useful next target for modular obstruction / CRT
  experiments, but it is not evidence that a zero is nearby.
- The random/sample computations neither prove A304081 nor extend OEIS's reported
  exhaustive verification frontier of `2*10^10`; they are sampled. The exact
  `verify-range` work reported below is a separate exhaustive finite extension.

## Exact post-frontier extension

The final source adds a `verify-range` mode that exhaustively visits every
integer in an inclusive interval while stopping after the first valid
representation for each `n`. Unlike `random` / `sample`, this is not
sampling.

Five consecutive 10,000,000-integer blocks immediately above the OEIS-reported
verification frontier were completed on the final search logic.

The final C++ source artifact in this PR is Git blob `66ba91adea522a7d5b5320a2ed7aa2270c3f1045`. The
outputs below are the builder-recorded execution evidence for that source; the
independent review checked the algorithm and selected arithmetic but did not
re-run all 50,000,000 integers. The exact reproduction commands are:

```bash

./a304081_search verify-range 20010000001 20020000000
```
