# Complete totient preimages for a finite target family

This exact index covers every positive n with φ(n) dividing 20736. Its 45 target divisors yield 41 attained values and 1,314 positive preimages. The fiber φ(n)=20736 has 173 members, with least 21037 and greatest 103740.

The complete certificate retains all candidate-prime trials, exponent options and 1,035 suffix cells. A saved reader provides counts, numeric extrema, exponent-lexicographic rank/select, pages and exact membership. All 37 fresh query outputs are retained; query arithmetic is counted separately from construction.

See [the API guide](TOTIENT_PREIMAGES_API.md) for the completeness proof, DLMF convention, source identity, usage and limits. This exhausts selected finite fibers without a cutoff on n; it does not settle Erdős 51's infinite least-preimage-ratio question.
