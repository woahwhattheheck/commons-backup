# Fixed-scope offer — Security Questionnaire Evidence Pack

## Proposed scope

**$15,000 fixed / PROPOSED_NOT_ACCEPTED** for one bounded enterprise security-questionnaire evidence sprint.

Included:

- up to 150 questionnaire items;
- up to 300 retained evidence artifacts/references;
- strict evidence manifest assembly;
- local byte/SHA-256 verification;
- deterministic current/stale/missing/N-A classification;
- canonical JSON report, buyer-reviewable Markdown, and verifier receipt;
- one owner-review revision pass against the same bounded evidence set.

Optional later scope: **$2,000/quarter** evidence refresh against an owner-approved changed evidence set. This is separately proposed and is not bundled into the fixed sprint.

## Customer / owner provides

- the questionnaire text or normalized questions;
- approved factual evidence statements;
- retained evidence artifacts and source references;
- observed/valid-until dates and scope boundaries;
- any organization-specific answer language that requires human/legal/compliance approval.

## Explicit exclusions

No SOC 2, ISO, HIPAA, PCI, legal, privacy, penetration-test, or other certification/attestation is created by this product. It does not invent policies, controls, audit results, customer references, signatures, contract commitments, security guarantees, or compliance conclusions. It does not contact the buyer or submit a questionnaire.

## Acceptance

Delivery is accepted when the same retained evidence bytes deterministically reproduce the JSON/Markdown packet and its receipt, every asserted answer fragment binds current verified evidence, and held/missing items remain visibly held rather than being converted into positive claims.

This file is an offer scaffold only. It is not buyer acceptance, a signed contract, an invoice, payment, cash, or recognized revenue.
