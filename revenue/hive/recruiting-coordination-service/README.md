# Recruiting Coordination Service

Hive demand `bm-hive-20260908-045` — a customer-usable, dependency-free interview logistics workspace for small employers and fractional recruiting teams.

**Proposed offer:** $299/month for a bounded interview pipeline. This repository artifact is the working product; it does not establish a sale, subscription, or earned revenue.

## What it does

- Keeps candidate, interviewer, and recruiter intake in one local JSON workspace.
- Collects offset-aware availability and finds times shared by the candidate and exactly two interviewers.
- Schedules and reschedules interviews only when every participant is available.
- Prevents double-booking when two candidate panels share an interviewer.
- Produces candidate/interviewer message drafts and reminder drafts for recruiter review.
- Produces a one-candidate recruiter handoff packet with slot history after a reschedule.
- Atomically persists scheduling state.

## What it deliberately does not do

It never scores, ranks, recommends, accepts, rejects, or hires applicants. Those fields are rejected from the workspace. It never sends email, SMS, calendar invitations, or other messages; every generated message has `send: false`. The employer owns hiring judgment and the recruiter owns communication through their existing tools.

## Quick start

Use the included sample as a disposable workspace:

```bash
cp example_workspace.json /tmp/interviews.json
python recruiting_coordination.py /tmp/interviews.json slots app-001
python recruiting_coordination.py /tmp/interviews.json schedule app-001 2026-09-14T14:00:00Z
python recruiting_coordination.py /tmp/interviews.json packet int-app-001-1
python recruiting_coordination.py /tmp/interviews.json reminder int-app-001-1
```

To move an interview:

```bash
python recruiting_coordination.py /tmp/interviews.json reschedule int-app-001-1 2026-09-15T16:30:00Z
```

All datetimes must include a UTC offset. Output is normalized to UTC (`Z`).

## Workspace shape

`people` stores candidates, interviewers, and recruiters. Candidate rows bind one candidate person to exactly two interviewer IDs and one recruiter. `interviews` is generated by the service. Keep the file in customer-controlled storage because it contains contact information.

## Acceptance mapped to the build demand

A candidate plus two interviewers can reach a common valid slot; a shared-interviewer collision is rejected; the same interview can be rescheduled with prior-slot history; and the resulting candidate/interviewer drafts contain no other candidate identity. Missing or conflicting availability fails closed instead of guessing.

Run the focused suite:

```bash
python -m unittest -v test_recruiting_coordination.py
```
