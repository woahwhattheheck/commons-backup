Current order answers. Confirmed return requests. A visible queue for the team.

This desk runs locally. The call walk-through below uses text and keypad inputs, not a telephone call. Connect the webhook to the shop's existing voice service separately. Returns are requests for review, never automatic refunds.

1. Shop policy and transfer destination

Save the shop's actual policy before automated return intake. A blank phone keeps handoffs in the queue and explicitly tells callers that no live transfer is configured.

2. Load the shop's order export

Import is an atomic upsert: absent orders are retained and return IDs do not change. Supply only these five fields; no addresses, payment details or customer names are needed.

order_ref,status,eta,delivered_on,returnable
1001,delivered,Delivered,2026-09-01,true
1002,shipped,Carrier expects Friday,,false
Statuses: processing, shipped, delivered, cancelled. Delivered dates use YYYY-MM-DD. Returnable is literally true or false. Invalid rows roll back the whole import.
