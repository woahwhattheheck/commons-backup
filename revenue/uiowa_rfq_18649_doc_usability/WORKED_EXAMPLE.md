# Worked fictional example

The synthetic inventory demonstrates three evidence states.

- ESS / D01: a short workflow overview is available, recently reviewed, and has a maintainer role. A bounded walkthrough can test whether another practitioner can answer one dependency question from it. Recency alone does not prove correctness.
- RIS / D02: a decision note is available but old and has no recorded maintainer role. Review it against one current task before deciding whether it needs revision.
- IAM / D03: an expected starter guide was not located. Record a documentation-support gap, not a conclusion about the underlying onboarding practice.

These cases intentionally distinguish adequate lightweight notes, stale documentation, and not-located documentation. Unknowns remain unknown until another source or walkthrough resolves them.
