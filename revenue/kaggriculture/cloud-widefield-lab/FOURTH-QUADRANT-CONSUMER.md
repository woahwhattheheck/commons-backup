# Prospective work-bundle consumer

`fourth_quadrant.py` evaluates complete worker schedules over compatible authored
routes. The economic admission callback receives dated incremental costs and
explicit product deliveries, and selects an evaluated proposal or returns `None`.
The canonical controller consumes this component before the selected-action SELL
boundary. Default configuration does not enable new investment.

Retain one `FourthQuadrant` instance across controller reconstruction. Install it
on the rebuilt controller, configure it before production, and call `finish` with
the action actually returned after the deadline guard. An unreturned producer does
not commit a new work bundle. Completed selected fallbacks retain their bundle.
Added planting requests enter the existing route-derived seed budget.

The optional existing spatial component operates before admission. Once a bundle
owns worker schedules, its actions remain intact. All incumbent worker spawns and
route-switch prefix comparisons retain their existing semantics. An observed
worker or position mismatch stops further optional spending and records the abort.

The planner does not infer future shops, rival actions, weather, or guaranteed
receipts from a current quote. Economic admission must account for all incumbent
operating obligations, shed capacity at delivery, market demand and remaining
horizon. A funded physical counterfactual is an experiment, not an admission rule.

`economic_program(proposal, route_id, base_route)` returns the full proposed route
and a concrete bundle with land order location, rejoin boundary, and per-tile
planting, watering, harvest, drop and sale slots. Explicit sale intents follow the
baseline market prefix and still pass through the single selected SELL consumer.
ECON derives physical and financial outcomes from that program rather than
trusting a claimed receipt or a current-quote multiplication.

Exact full-game observations, outcomes, development counterfactuals, failed checks,
timings and analysis are retained in the private task evidence. The public source
contains no hosted replay or private opponent continuation.
