## Behavior

`arms/sell.py` previously re-exported `scheduler.agent` directly. The unchanged scheduler treats an absent `step` as zero when deciding whether to construct its singleton, then requires `obs['step']` inside the decision. Public day/hour observations therefore repeatedly enter the reset path and fail on the missing field.

The existing arm now supplies `day * turnsPerDay + hour` only when step is missing or None, using the caller's day length (default 24). It copies the outer observation to add that field and calls the SAME original scheduler once. An explicit step, including an explicit zero, keeps the original observation object, configuration, reset semantics and action path. Nested observation values are not needlessly copied. Missing or invalid public clock values are not converted into an invented zero.

No strategy, candidate selection, producer, worker action, vendor implementation, input archive, profiler, workflow or separate opponent wrapper is added or changed. The public callable remains `agent(obs, configuration=None)` at the same path. Fresh consumers can use this arm directly; existing frozen experiments keep their original source and adapters.
