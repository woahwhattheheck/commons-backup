## The integration property

The parent compiler uses `software` while the UI-only demonstration uses `software_development`. Treating the UI sample as the only input contract rejects real compiler exports. The separate `native_handoff.convert` adapter preserves original cell spelling, all twelve source notes, the supplied report receipt, and the complete source envelope. Its `register_cell` is an explicit internal alias, never a renamed source record. Mixed vocabularies are rejected rather than guessed.

Browser notes remain unclassified intake: `finding_id` and `kind` are null until an analyst supplies that meaning. Receipt/hash agreement is a content binding, not evidence authenticity or approval.

## Run in a cloud checkout

The Python register remains standard-library-only. This optional integration rehearsal needs Playwright and a Chromium executable already available in the test environment. It performs no dependency installation and no external model or provider call. Use a new output directory whose parent exists.

From the repository root:

```sh
python revenue/uiowa_rfq_18649_review_register/browser_contract_rehearsal.py --source-root . --chromium /usr/bin/chromium --out /tmp/a91c-browser-normal
python -O revenue/uiowa_rfq_18649_review_register/browser_contract_rehearsal.py --source-root . --chromium /usr/bin/chromium --out /tmp/a91c-browser-optimized
```

Use distinct unused directory names on later runs; the rehearsal deliberately refuses to reuse an existing output directory. Missing browser dependencies or failed assertions return a nonzero exit, not a skip labeled as success. Assertions use explicit exceptions and remain active under `python -O`.

## What actually executes

The script builds a small fictional evidence collection and calls the real parent `compile_untrusted_inspection`, followed by the real semantic integrity verifier. The produced report has nine evidence-consistent cells and one each with conflicting, missing, and stale evidence; every maturity/confidence value remains null in this untrusted inspection.

Chromium loads the actual current HTML structure and JavaScript, offline. The harness supplies the compiled report through `installReport`, edits all twelve cells using browser controls, filters the display to three software cells, and downloads the actual JSON export. The downloaded export still contains all twelve cells. The native adapter converts and then recomputes verification against that original handoff.

The run also checks three negative cases: a fabricated intake note with a newly calculated digest, a mixed native/legacy vocabulary, and a changed source report receipt. All must be rejected. Reinstalling the same report must clear all notes/dispositions. Loading the legacy UI sample must retain its legacy cell spelling and UI-only provenance label.
