# Proposed offer — security evidence remediation sprint

**Commercial state: `PROPOSED_NOT_ACCEPTED`.**

The product supports a bounded **$5,000–$30,000 fixed implementation sprint** assembled from owner-proposed line items that close evidence-backed security/procurement HOLDs.

## Included shape

- bind one immutable source findings packet;
- translate held/partial rows into concrete technical or evidence deliverables;
- preserve source requirement, current-state, gap, and evidence IDs;
- define observable acceptance tests and owner/customer dependencies;
- define explicit change-control triggers so new systems, production rollout, certifications, audits, or broader scope do not silently enter the fixed fee;
- emit deterministic JSON + owner/buyer-reviewable Markdown + verification receipt.

## Exclusions

No certification, attestation, legal/compliance opinion, audit guarantee, penetration test unless separately and explicitly scoped, buyer contact, contract signature/acceptance, production deployment, invoice approval, payment collection, or revenue recognition is created by this package.

A valid scope is still only a proposal artifact. A buyer or authorized owner must separately accept commercial terms and authorize any implementation work.
