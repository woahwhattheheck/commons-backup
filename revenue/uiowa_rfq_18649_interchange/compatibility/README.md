## The interface boundary that matters

The actual workbench's `exportDraft()` emits cell notes, dispositions, compiler statuses and a report receipt. It does **not** emit the original source IDs, source-record hashes, reason codes, candidate, or evidence-authority records. Preserve the matching original report alongside the draft; never convert the draft alone into an apparent complete assessment.

`audit_pair(report, handoff)` diagnoses receipt-generation mismatch, metadata/status disagreement, missing/duplicate/unknown cell keys, omitted source context, altered synthetic labels and nonliteral-false draft authority fields. It is a **consistency check**, not the parent compiler's semantic verifier or independent evidence authentication. A matching arbitrary receipt does not establish provenance.

`compare_json(original_text, returned_text)` uses a separate Decimal-aware parser. It distinguishes booleans from integers, null from empty/absent values, strings from numeric identifiers, Unicode code points, line endings, array order and exact decimal values. Object-key ordering and equivalent decimal notation may differ. The result explicitly separates semantic equality from byte identity. Diagnostics report JSON Pointers and change codes, not source values.

Capture/output destinations must not exist. `WORKBENCH_APP_JS` and `WORKSHARE_DIR` can select explicit reviewed sibling checkouts for tests. `run_transport.py` takes **trusted executable module source**, not an intake document. ## Reproduced transport finding

Against TESSELLA transport blob `735928df43423507dbf8206fb12e3d28112ed613`, **11 of 15 independent trials passed and four failed**. The captured report and draft, synthetic evidence/recommendations, a large integer, negative zero, and the returned report/draft join survived the tested row/CSV paths.

High-precision decimal and underflow inputs changed on both paths. For example, `0.123456789012345678901` became `0.12345678901234568`; `1e-400` became zero. Loss occurs at the initial binary floating-point JSON parse, so comparing two documents after that parse can falsely appear successful. The finding was delivered to the canonical owner; preserve exact decimal tokens or reject unsupported numeric inputs before claiming lossless ingestion. `EXECUTION.json` records each observed trial and the exact source version. A later repaired blob needs its own execution receipt; these failures must not be silently relabeled as a pass.
