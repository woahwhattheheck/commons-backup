## Why the compiler has hard trust roots

The candidate worksheet cannot mint readiness. Public `compile_current()` only trusts packet,
owner-evidence, or partner-evidence bytes if their exact SHA-256 is pinned in reviewed source.
All three roots are `None` today. Acquiring the official packet is therefore a **source-generation
event**, not a JSON toggle.

This deliberately makes the current carrier impossible to self-author into PRIME/TEAMING readiness.

## Qualification routes

The engine evaluates both routes:

- **PRIME** — requires the retained official package plus retained evidence for legal entity,
  higher-ed references, named key personnel, insurance, financial capacity, student-data privacy,
  security, accessibility, integration experience, implementation/support, and AI governance.
- **TEAMING** — can combine retained owner and retained partner evidence, but a candidate-written
  `CLAIMED_COMMITTED` field never counts as a commitment.

Strongest outputs are `READY_FOR_OWNER_PRIME_REVIEW` or
`READY_FOR_OWNER_TEAMING_REVIEW`. Neither state authorizes submission, contact, signature,
pricing/staffing commitment, award claims, payment claims, or revenue recognition.

## Package-acquisition runbook

Before any bid/no-bid or external action:

1. Recover the **complete current Jaggaer event** and every attachment/addendum/questionnaire.
2. Record exact filenames, buyer source URLs, publication/version metadata, and SHA-256 of exact bytes.
3. Build one authoritative requirement table whose every row binds a document ID + exact digest.
4. Extract evaluation weights, mandatory respondent qualifications, references/personnel, required
   integrations, privacy/security/accessibility/AI-governance controls, pricing, contract/support
   term, insurance/legal forms, HUB/subcontracting treatment, question/communication rules, and
   submission checklist.
5. Update the retained official packet root in reviewed source only after an independent byte/source
   pass.
6. Separately build retained owner/partner evidence ledgers. Repo features are not customer references.
7. Recompile. Choose `PRIME`, `TEAMING`, or `NO_BID/HOLD` from evidence, not optimism.

specialist workshare** for a qualified higher-education/student-success prime. Candidate seams include

single-writer Muse arbitration before any email/DM is sent.
