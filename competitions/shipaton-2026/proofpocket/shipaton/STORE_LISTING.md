# Store listing draft

**Name:** ProofPocket

**Short description:** Turn completed work into portable, tamper-evident proof receipts.

**Long description:**
ProofPocket is a privacy-first evidence notebook for freelancers, operators, builders, and anyone who needs to show what was done without uploading the underlying work to another server. Create a project, write a bounded completion claim, attach local files, and ProofPocket hashes the evidence on-device into a deterministic receipt. Export the JSON receipt for verification later; Pro users can also export a concise PDF proof pack.

Evidence files stay local to the device through ProofPocket. The app records file metadata and SHA-256 content digests, not hidden cloud copies. If a claim or evidence digest changes, receipt verification fails. ProofPocket calls this tamper evidence—not identity signing.

Free includes 3 local projects and JSON receipt verification. ProofPocket Pro unlocks unlimited projects and PDF proof packs through an in-app purchase/subscription managed by RevenueCat.

**Privacy:** No ProofPocket account, ad SDK, analytics SDK, or evidence upload. Network use is limited to store/RevenueCat purchase and entitlement operations.
