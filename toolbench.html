python host/toolbench.py --db /chosen/cloud/path/bench.sqlite3 --example

Run in an existing cloud workspace. Preserve the chosen data file across restarts. Any HTTP-capable harness can use GET /api/state, GET /api/source?id=…, and POST /api/op. No plan or ordered route is required.
Example loading supplies synthetic objects only. It does not link, select, approve, or resolve anything. This bench has no account wall; anyone who can reach it can read and change its data.
