Receipt contract

Normalized receipt fields: source SHA, test identity, runner-neutral command envelope (argv/cwd/env/timeout_s/shell=false), exit code, duration_ms, artifact paths+sha256+bytes, provider, run URL (null unless measured or fixture://), terminal state. Reconciler findings cover equivalent results, missing shards, stale-source runs, artifact drift, contradictory exits, retries, duplicate receipts, hash mismatch, cancellation, and malformed schemas.
