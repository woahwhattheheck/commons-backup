What a real stop path is

Hard halt

A boundary the agent cannot route around — not a budget alert, not a log line, not a dashboard tile. When the halt fires, the run ends. The proof shows the halt firing, not a promise that it would.

Rollback

State returns to a known point, so stopping the agent does not mean losing the work. The lost-work risk is real: paying users report lost agent session work in an open issue on anthropics/claude-code (#64403). A stop without rollback trades a runaway for a lost session.

Durable receipt

Target, result, timestamp, and limits — a record that survives the session, links the proof, and states what it does not establish. If the receipt does not say what was not proven, it is marketing, not a receipt.
