# Frozen acceptance contract

The original build demand requires a read-only dossier compiler over eight input classes: batch identity; CO2 source certificate; renewable-power certificate/time window; catalyst/electrolyzer lot; recipe revision; in-process lab result; final fuel-spec/COA result; and tank/shipment chain of custody.

The frozen acceptance corpus is generated by `synthetic_acceptance.py`: 100 synthetic batches, of which 24 unique records are faulty. Exactly three records are faulted in each of the eight input classes. `compiler.py` must emit exactly 76 complete dossiers and 24 batch+reason exceptions.

Run:

```bash
python3 -m unittest discover -s tests -v
python3 synthetic_acceptance.py /tmp/ejet-100.json
python3 compiler.py /tmp/ejet-100.json --out /tmp/ejet-out || test $? -eq 2
```

A complete dossier carries field-level JSON-path lineage and a SHA-256 over the canonical lineage object. The tests resolve every lineage path back into the source record and assert exact value equality, so the compiler cannot invent evidence values. Both dossiers and exceptions explicitly set `automated_release=false` and `release_decision=null`. The compiler has no PLC/DCS, recipe/setpoint, blending, tank/valve, certification, batch-disposition, or shipment-authorization action.
