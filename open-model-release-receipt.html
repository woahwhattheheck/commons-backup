A local, evidence-first gate for one open-model release manifest. It verifies exactly eight declared artifacts, recomputes every SHA-256, runs one manifest-declared loader, and emits JSON plus a static HTML receipt.

Binary acceptance

  • PASS only at 8/8 matching artifacts and loader exit 0.
  • Any missing path, changed byte, timeout, or loader error is FAIL with the exact stage.
  • Inputs are capped at 10 MiB and loader execution at 60 seconds; filesystem, network, database, training, and publication side effects of the manifest-declared loader are outside this receipt's assurance.
  • The receipt does not itself deploy or publish the release.
